== Reikwijdte

_Energieprofielen_ is de verzamelnaam voor een aantal dataproducten. Elk van deze dataproducten bevat een open dataset van profielen die per gebied geaggregeerd zijn. Het verschil tussen de dataproducten ligt in het gekozen gebied en de wijze waarop de energieprofielen geaggregeerd zijn. Het aggregeren gebeurt op basis van SBI (de Standaard BedrijfsIndeling van de het CBS op basis van de KvK) of op basis van energiedrager (gas of elektriciteit). In geval van elektriciteit wordt er nog onderscheid gemaakt tussen KV (kleinverbruik) versus GV (grootverbruik) en tussen Afname versus Invoeding. Voor de leesbaarheid heb ik het over Energieprofielen, maar wanneer het onderscheid relevant wordt dan wordt dat uiteraard vermeld.

De Energieprofielen geven inzicht in energieverbruik en -opwekking op gebiedsniveau. Dit inzicht wordt gebruikt voor een betere besluitvorming over netcapaciteit, congestiebeheer en energietransitie.

=== Integratiepatroon
De dataset van een dataproduct wordt ontsloten middels een dataservice. Hier zijn drie integratiepatronen voor: _bulk_, _request_ en _streaming_. Op basis van de bovenstaande tabel is gekozen voor het integratiepatroon _request_ (REST API). Een REST API (Representational State Transfer Application Programming Interface) is _een set van regels en conventies die het mogelijk maakt voor systemen om met elkaar te communiceren via het web_. Bijvoorbeeld om de dataset van een dataproduct op te halen. Een REST API heeft input-parameters (de vraag) en output (de dataset). Voor Energieprofielen zijn de input-parameters het gebied en de datavelden waarover geaggreerd moeten worden.
